# Software-Inventar-

This repository handles XML task management and software inventory.

## Project Files
* **software_inventar.py** - Main Python script for processing inventory data.
* **software.xml** - XML database file containing software records.
* **XML Handling Task Sheet.pdf** - Project assignment and requirements documentation.

## How to Run
To run the script, open your terminal and execute:

#bash
python3 software_inventar.py
